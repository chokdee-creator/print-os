# Study workspace redesign

Brief from the existing user requests: redesign the learning dashboard using Scroll Craft, retain every existing function and all stored user data. The existing navy/gold identity, Thai language and personal course workflow are established inputs. No new student data, grades or prices are invented.

Audience/task: an individual student reviewing progress, managing courses, transcript history, study-plan membership and exam slots.
Offer/next action: open the desired working view or add a course. This is a dashboard, not a marketing landing page.
Tone: composed, premium and encouraging; ink navy #14283f, warm gold #e7bc65, paper-neutral #f2f4f7, white #ffffff, muted slate #627187.
Typography: retain locally available Thai-capable sans-serif; emphasize useful totals and view titles.
Grammar: live working surface. Fixed navigation, concise layered overview, direct metric links, familiar tables and dialogs. No pinned narrative or extra scroll distance.
Signature: a layered study-progress folio with the real earned-credit total and a gold route motif. Layers react gently to scroll and fine-pointer position without capturing the pointer. The same composition resolves to a complete static state on reduced motion and touch.
Feeling curve: calm orientation from the overview; clarity from real totals and progress; confidence in predictable CRUD and recovery; a clear finish through backup/import.
Peak: the progress folio connects a premium visual treatment with actual student progress; it does not displace the working tools.
Assets: existing icon symbols and authored HTML/CSS/SVG; no generated photo, third-party media or video pipeline required.
Mobile: simplify layer travel, stack content, retain search and navigation, keep table overflow local.
Preserve: IDs and handlers, curriculum/transcript data, storage keys, plan-only removal, catalog deletion/recovery, demo separation, backups/imports and grade calculations.
Verification: existing data/selection tests; UI checks for navigation, forms, transcript/history, selection and dialogs; desktop/mobile overflow and static/reduced-motion behavior.
